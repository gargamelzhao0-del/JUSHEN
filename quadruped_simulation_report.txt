【控制算法分析 / Control Algorithm Analysis】
--------------------------------------------------------------------------------

  数据流路径:
    ┌──────────────────────────────────────────────────────────────────┐
    │ 上位机 trot_gait_simulator.py (50Hz)                          │
    │   └── 生成Trot步态 → 12个电机目标角度 → TCP发送               │
    └──────────────────────────────────────────────────────────────────┘
                                    ↓ 50Hz, 20ms间隔
    ┌──────────────────────────────────────────────────────────────────┐
    │ STM32 TCP接收 → quad_command_fusion.c                         │
    │   └── 历史缓冲(32帧) → 前瞻缓冲(10帧) → 曲率计算 → 轨迹规划   │
    └──────────────────────────────────────────────────────────────────┘
                                    ↓
    ┌──────────────────────────────────────────────────────────────────┐
    │ trajectory_planner.c (200Hz)                                  │
    │   └── 梯形/S曲线规划 → 状态机(IDLE→ACCEL→CRUISE→DECEL)       │
    └──────────────────────────────────────────────────────────────────┘
                                    ↓
    ┌──────────────────────────────────────────────────────────────────┐
    │ quad_smart_controller.c                                       │
    │   └── 场景识别(SWING/STANCE) → 策略选择 → 力位混合控制       │
    └──────────────────────────────────────────────────────────────────┘
                                    ↓
    ┌──────────────────────────────────────────────────────────────────┐
    │ CAN发送优化 (100-500Hz自适应)                                 │
    │   └── 位置阈值判断 → 速度阈值判断 → 智能跳过策略              │
    └──────────────────────────────────────────────────────────────────┘
                                    ↓
    ┌──────────────────────────────────────────────────────────────────┐
    │ 电机响应模型                                                   │
    │   └── PD控制 → 电机动力学 → 位置/速度输出                     │
    └──────────────────────────────────────────────────────────────────┘

  关键算法说明:

  1. 轨迹规划 (TrajectoryPlanner):
     • 使用梯形速度曲线或S曲线进行平滑
     • 状态机: IDLE → ACCELERATING → CRUISING → DECELERATING → STOPPING
     • 自动计算加减速距离，实现无超调到达目标

  2. 前馈+PID控制:
     • 速度前馈: 补偿电机惯性
     • 加速度前馈: 补偿动态响应
     • PID反馈: 消除稳态误差

  3. CAN发送优化:
     • 仅当位置/速度变化超过阈值时发送
     • 加速/减速阶段提高发送频率
     • 节省CAN总线带宽
