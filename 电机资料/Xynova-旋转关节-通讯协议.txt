CANFD 通讯协议文档
一、说明
本文件为 CANFD 通讯协议命令文档，用于描述各类控制与参数配置命令的功能、数
据长度、写入说明以及返回数据说明。
二、物理层约束
2.1 CAN-FD 接口与物理层约定 
• 通信接口：CAN-FD
• 标识符类型：扩展标识符（29bit）
• 帧类型：数据帧
• 禁用：
o 标准标识符（11bit）
o 远程帧（Remote Frame）
2.1.1 位速率配置（默认） 
阶段 速率 采样点
仲裁阶段 1 Mbps 80%
数据阶段 5 Mbps 80%
2.2 扩展标识符（29bit）定义 
CAN-FD 扩展标识符采用字段化设计，各比特定义如下（Bit0 为最低位）：
位描述 预留 设备 ID 预留 消息 ID 
范围 Bit28~Bit19 Bit18~Bit12 Bit11~Bit10 Bit9~Bit0
长度 10Bit 7Bit 2Bit 10Bit
 
2.2.1 位定义说明 
位端 名称 位宽 说明 
Bit9~Bit0 消息 ID 10
Bit11~Bit10 预留
Bit18~Bit12 设备 ID 7 范围 1~127
Bit28~Bit19 预留
 
2.3 Device ID 约定 
• 每个设备在同一 CAN-FD 总线上必须具有唯一的 Device ID
• Device ID 支持范围：0x00 ~ 0x7F
• 约定：
o 0x00：广播地址
o 0x01：默认地址

四、控制示例
1. 先发送 消息 ID“0x0001”，对设备进行使能。
2. 发送 消息 ID “0x0002”，切换至期望的运行模式。
3. 发送 消息 ID “0x0004”，开始运行。
4. 发送 消息 ID “0x0131”或 “0x0133”或 “0x0134”进行目标值设置。
